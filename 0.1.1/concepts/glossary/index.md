# Glossary

These terms describe EON's representations, learning and prediction. Package objects and interfaces are introduced in [Package and Recipes](https://entropiclearning.github.io/entlearn/0.1.1/guide/package/index.md).

| Term                     | Meaning                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Affiliation**          | An observation's membership distribution over a block's clusters, concentrated in one cluster for hard assignments or spread across clusters for soft assignments. See [Affiliations](https://entropiclearning.github.io/entlearn/0.1.1/concepts/representation/#observations-and-affiliations)                                                                              |
| **Centroid**             | A cluster's representative point or categorical distribution in input space, or its representative target vector for regression. See [Input geometry](https://entropiclearning.github.io/entlearn/0.1.1/concepts/representation/#standard-input-geometry) and [output centroids](https://entropiclearning.github.io/entlearn/0.1.1/concepts/representation/#regression-head) |
| **Discretisation error** | The error of representing an observation by an input cluster's geometry. See [Standard error](https://entropiclearning.github.io/entlearn/0.1.1/concepts/representation/#the-discretisation-error) and [manifold error](https://entropiclearning.github.io/entlearn/0.1.1/concepts/representation/#manifold-geometry)                                                        |
| **Transition matrix**    | A matrix relating source clusters to target clusters or classes. See [Transitions](https://entropiclearning.github.io/entlearn/0.1.1/concepts/representation/#transitions-between-clusterings)                                                                                                                                                                               |
| **Coupling**             | A transition's normalisation constraint, with columns summing to one under M and rows summing to one under S. See [Coupling conventions](https://entropiclearning.github.io/entlearn/0.1.1/concepts/representation/#transitions-between-clusterings)                                                                                                                         |
| **Weights**              | Probability vectors controlling contributions of features, training observations or regression output dimensions to the loss. See [Feature, instance and output weights](https://entropiclearning.github.io/entlearn/0.1.1/concepts/representation/#feature-instance-and-output-weights)                                                                                     |
| **Entropy penalty**      | A negative-entropy term added to the loss, smallest for spread-out affiliations or learned weights. See [Entropy penalties](https://entropiclearning.github.io/entlearn/0.1.1/concepts/loss/#entropy-penalties)                                                                                                                                                              |
| **Temperature**          | A coefficient balancing entropy against cost. See [Affiliation regimes](https://entropiclearning.github.io/entlearn/0.1.1/concepts/learning/#affiliation-temperatures) and [weight regimes](https://entropiclearning.github.io/entlearn/0.1.1/concepts/learning/#temperatures-and-effective-dimension)                                                                       |
| **Effective dimension**  | An entropy-based measure of how broadly a distribution spreads its weight. See [Effective dimension](https://entropiclearning.github.io/entlearn/0.1.1/concepts/learning/#temperatures-and-effective-dimension)                                                                                                                                                              |
| **Pruning**              | Removal of clusters with numerically zero unweighted affiliation mass and their associated parameters. See [Pruning](https://entropiclearning.github.io/entlearn/0.1.1/concepts/learning/#pruning)                                                                                                                                                                           |
| **Read-out**             | The rule converting final affiliations into a prediction. See [Read-outs](https://entropiclearning.github.io/entlearn/0.1.1/concepts/prediction/#reading-out-a-prediction)                                                                                                                                                                                                   |
| **Iterative prediction** | Repeated updates of query affiliations and prediction coordinates, including recovered instance weights when available, with learned parameters fixed. See [Iterative prediction](https://entropiclearning.github.io/entlearn/0.1.1/concepts/prediction/#iterative-prediction)                                                                                               |
