# Tutorial series

Choose a notebook below. **Read** opens a rendered notebook with its outputs on this site.
The figures remain interactive, but changing a notebook control does not rerun Python.
**Source** opens the Python file on GitHub.

The molab links open the notebooks in **server mode**, where Python can run PyTorch.
The notebook headers name the dependencies to install, including entlearn from PyPI.
Molab may require sign-in to start a server; check its current access terms.
