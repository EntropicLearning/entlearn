# Entlearn

`entlearn` implements Entropy-Optimal Networks (EON) for classification and regression.
It learns cluster representations and, when enabled, feature and instance
weights. We provide a PyTorch-based `Network` and a scikit-learn estimator.

## Installation


!!! warn "This is a prerelease!"

    The package is not yet on PyPI, so please install it from GitHub with `pip install git+https://github.com/EntropicLearning/entlearn` (or `uv add git+https://github.com/EntropicLearning/entlearn`).


To install the package from PyPI run:

```bash
pip install entlearn
```

See [Installation](guide/installation.md) for requirements, optional features and development setup.
