# Entlearn

`entlearn` implements Entropy-Optimal Networks (EON) for classification and regression.
It learns cluster representations that are optimal for a given learning task and, when enabled, simultaneous feature selection and outlier detection. We provide a PyTorch-based `Network` and a scikit-learn interface (including estimators).

## Installation

To install the package from PyPI run:

```bash
pip install entlearn
```

You can also install it from GitHub with
```bash
pip install git+https://github.com/EntropicLearning/entlearn
```
or
```bash
uv add git+https://github.com/EntropicLearning/entlearn
```

See [Installation](guide/installation.md) for requirements, optional features and development setup.
